# 🧪 실험 요청서: Gen-DT 제로샷 BOP 생성 성능 측정 (v3.2)

본 문서는 **Gen-DT (Generative Digital-twin Prototyper)** 연구를 위한 LLM 제로샷 성능 측정 가이드라인입니다.

## 1. 데이터 및 경로 설정
* **데이터 위치:** `./ex1/` 폴더 내 JSON 파일을 반드시 먼저 확인하십시오.
* **참조 파일:** `ground_truth_bop_v3.1.json` (한글/영어 공정 정답 데이터)
* **주의사항:** 실험 시작 전 `ex1` 폴더의 데이터 구조를 로드하여 제품명과 정답 단계를 파악하십시오.

## 2. 대상 모델 (Benchmark Models)
연구의 변별력을 위해 아래 5종의 모델을 대상으로 실험을 수행합니다.
1. **Gemini-2.5-Flash** (속도 및 효율성 체급)
2. **GPT-5-mini** (최신 소형 고성능 모델)
3. **GPT-4o** (업계 표준 성능 모델)
4. **OpenAI o1/o3-mini** (복잡한 공정 추론 특화 모델) - **[추가 추천]**
5. **Llama-3.3-70B** (대표 오픈소스 모델) - **[추가 추천]**

## 3. 실험 프로토콜 및 프롬프트
기존에 설정된 BOP 생성용 프롬프트를 일관되게 사용합니다.

* **프롬프트:**
  > "당신은 전문 제조 공정 엔지니어입니다. [PRODUCT_NAME]을(를) 생산하기 위한 대규모 컨베이어 기반의 표준 제조 공정(BOP)을 순서대로 나열하세요. 각 단계별 필수 설비 정보를 포함하여 아래 JSON 형식으로 출력하십시오.
  > 
  > {
  >   "product_name": "[PRODUCT_NAME]",
  >   "bop_steps": ["step1", "step2", ...],
  >   "equipment": ["equip1", "equip2", ...]
  > }"

* **설정:** $Temperature = 0.0$ (재현성 확보), 외부 검색 금지.

## 4. 어시스턴트 수행 과제
1. **경로 확인:** `ex1` 폴더 내 JSON 데이터를 읽고 제품 리스트(P01~P10)를 확인하십시오.
2. **배치 실행:** 각 모델 API를 호출하여 10개 제품군에 대한 제로샷 답변을 수집하십시오.
3. **정량 평가:**
    * **$n/M$ Accuracy:** 정답 데이터의 `bop_steps`와 모델 생성 결과를 비교하여 정확도를 계산하십시오.
    * **Sequence Match:** 공정의 논리적 순서가 어긋나지 않았는지 검증하십시오.
4. **결과 시각화:** 모델별 평균 정확도를 비교하는 표와 그래프용 데이터를 생성하십시오.
